# AIVES – AI-powered Viva Exam System (SWD392)

Design documents and the project tracker for AIVES, the oral exam system our team builds for SWD392. We build three features from the course list: Feature 3 AI Viva Interview, Feature 6 Feedback & Reporting and Feature 7 Access Control & Exam Configuration.

## Contents

`design/`
- `AIVES - Feature Description (EN).md`: what each of the three features does.
- `AIVES - System Architecture.docx`: software architecture design (modular monolith on ASP.NET Core, modules and the data they own, outside services, security, deployment).
- `SystemArchitecture.drawio`, `SystemArchitecture.png`: high-level architecture diagram.
- `UseCaseDiagram.drawio`: use case diagram (36 use cases).
- `SwimlaneDiagram.drawio`: 9 workflows as swimlane diagrams.
- `ConceptualERD.drawio`: conceptual ERD in crow's foot notation (15 entities).
- `ClassDiagram.drawio`: class diagram (17 classes, 9 enumerations).

`management/`
- `SWD392_AI_Oral_Exam_Project_Tracker.xlsx`: project tracker in Vietnamese (overview, dashboard, M1 tasks, roadmap, team roles, risks).

The `.drawio` files open in draw.io (diagrams.net) or in the Draw.io Integration extension for VS Code.
